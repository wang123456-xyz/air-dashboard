# 绵阳市空气质量监测可视化大屏

面向环保值班人员的空气质量监测与污染溯源辅助大屏：把分散在多个站点的
实时数据整合到一屏，帮助值班人员在 30 秒内判断哪个站点异常、污染物可能
从哪个方向传来。

**当前状态：v0.1 开发中（静态页面搭建阶段）**

## 项目基线（2026-11-26 锁定）

- 目标：12/13 前产出一个能通过网址访问的完整版本
- 范围：一屏静态大屏，含标题栏、4 个 KPI、3 个图表位、站点排行、明细表格
- 不做：多页面、登录、后端、三维场景、移动端适配
- 节点：11/29 骨架 / 12/06 首次部署 / 12/13 交付

## 数据来源

- 计划采集：绵阳市生态环境局公开空气质量数据
- 采集日期：待补充（12/07）

## 技术栈

- 已用：HTML5 / CSS3
- 规划中：JavaScript + ECharts、Python + FastAPI

## 运行方式

直接双击 `index.html`，或在目录下执行 `python -m http.server 8000`
